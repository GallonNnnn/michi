# Путеводитель в японский — правила работы с репозиторием

- Сайт: один файл `index.html`, публикуется через GitHub Pages: https://gallonnnnn.github.io/michi/
- Озвучка: `audio/f/*.mp3` (женский голос), `audio/m/*.mp3` (мужской), карта текст → файл встроена в `index.html` (`window.KANA_AUDIO`).
- Админка (`admin.html`) в репозиторий НЕ кладётся — она живёт только на компьютере владельца.

## Обновление сайта: всегда через технические работы
1. Сначала коммит, где в `status.json` стоит `"maintenance": true` — на сайте появляется плашка «Идут технические работы».
2. Затем коммит(ы) с изменениями.
3. После проверки — коммит с `"maintenance": false`.
